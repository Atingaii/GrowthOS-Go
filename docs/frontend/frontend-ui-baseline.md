# 前端 UI 设计基线

## 设计来源

本项目复用 `实现指定设计风格.zip` 中已经完成的 GrowthOS 页面设计，作为当前前端视觉基线。后续如产品需求与可用性验证发现问题，在现有组件和主题边界内调整，不另起一套视觉系统。

## 视觉原则

- Plus Jakarta Sans 作为界面主字体，JetBrains Mono 用于代码、指标和技术标识；
- 浅色暖灰背景、深色文字、低饱和蓝色主色；
- 通过留白、细边框、适度圆角和轻阴影建立层次；
- 用户端保持轻量触达感，运营端强调信息密度和状态清晰度；
- MCP 和 Agent 工作台保留深色科技感，但不牺牲可读性；
- 状态同时使用文字、图标和颜色表达；
- 页面必须支持桌面端与窄屏布局。

## 复用边界

公共图形、状态徽标、指标卡、布局和业务卡片位于 `web/src/components` 与 `web/src/layouts`。Mock 数据集中位于 `web/src/mocks`，页面不得散落虚假业务数据。
