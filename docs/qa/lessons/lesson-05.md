## 自动化证据

从仓库根目录执行：

```text
make verify
```

该命令校验 Go 测试、文档链接、课程状态、ADR 索引、章节 API 记录、前端类型和生产构建。

## 未覆盖与剩余风险

- 本节没有执行事件发布、消息投递、幂等消费或分析查询测试，因为这些能力尚未实现；
- 事件名称、版本、主题、分区键和保留策略只是分析输入，不能当作已实现契约；
- 领域事件与审计事件的最终存储边界留给第 6～7 节和后续实现；
- 当前前端继续使用 Mock 数据，不作为事件采集已经完成的证据。
