## 自动化证据

从仓库根目录执行：

```text
make verify
```

该命令校验 Go 测试、文档链接、课程状态、ADR 索引、章节 API 记录、前端类型和生产构建。

本次执行结果：通过。Go 测试、文档检查、TypeScript 类型检查和 Vite 生产构建均成功；Vite 提示入口 JavaScript 压缩后约 695 kB，属于现有前端框架的非阻塞体积提示，后续真实路由接入时进行代码分割。

个人文档镜像使用：

```text
make docs-sync VAULT=/mnt/e/TencentGo/growthOS
```
