- 当前主角是跨行业共同场景，具体行业支付、履约和风控旅程需在真实业务需求出现后扩展；
- 曝光可见阈值、频控周期和归因窗口尚未量化，留给行为协议、Feed 和非功能需求章节；
- 用户调研和可用性测试尚未执行，当前 v1 是后续原型验证的基线。
