## 自动化证据

从仓库根目录执行：

```text
make verify
```

该命令校验 Go 测试、文档链接、课程状态、ADR 索引、章节 API 记录、前端类型和生产构建。

个人文档镜像使用：

```text
make docs-sync VAULT=/mnt/e/TencentGo/growthOS
```

同步目标不进入 Git，仓库 `docs/` 仍是唯一事实源。

## 未覆盖与剩余风险

- 本节没有可执行领域代码，验收证据是模型一致性和文档漂移检查，不代表上下文已经物理隔离；
- 上下文数量、聚合、数据库和调用协议仍可能被后续 NFR 与实现证据推翻；
- Feed 曝光确认、奖励参与次数到账和外部转化归因仍需在对应业务章节细化；
- 当前前端继续使用 Mock 数据，不能作为任何上下文 API 已经实现的证据。
