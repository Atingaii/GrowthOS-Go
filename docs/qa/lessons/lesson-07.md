## 数值合理性评审

本节数值作为后续压力输入，而不是当前承诺：

- 生产候选峰值用于验证热点、缓存、异步、分片和服务拆分是否有必要；
- M0～M7 分阶段门槛避免 Modular Monolith 第一版承担终态容量；
- P99 均附带不包含的外部耗时，防止统计口径变化制造虚假优化；
- 可用性目标禁止通过假成功、重复扣减或跳过审批获得；
- 所有实测列保持“未测量/无”，没有填入估算数据。

## 自动化证据

从仓库根目录执行：

```text
make verify
```

该命令校验 Go 测试、文档链接、课程状态、ADR 索引、章节 API 记录、前端类型和生产构建。

个人文档镜像使用：

```text
make docs-sync VAULT=/mnt/e/TencentGo/growthOS
```

## 未覆盖与剩余风险

- 当前没有 Go 业务服务、数据库、Redis、MQ、可观测平台或压测环境，无法验证任何运行时目标；
- 容量数字尚未经过真实客户规模、业务比例和成本模型校准；
- 99.95% 等 SLO 要在持续监控和有效请求口径完成后才能计算；
- 审计保留和隐私默认值需要按具体行业、地区和部署方合规要求调整；
- 第 8 节仍需把业务边界、外部系统和质量约束映射为 V0 逻辑系统设计。
