## 后续契约约束

真实 API 或集成事件出现时必须说明：

- 哪个上下文拥有命令与业务校验；
- 响应表示“请求已接收”还是“业务事实已确认”；
- 查询返回权威事实、快照还是派生投影；
- 跨上下文调用失败、超时、重复和结果未知如何表达；
- 前端 Mock 与真实接口如何切换，哪些页面已经联调；
- 接口版本、错误码、幂等键和 `trace_id` 是否满足当时需求。
