## 后续真实契约必须表达

- 任务、计划和步骤版本；
- Tool 名称、Schema 版本、关键参数和业务请求号；
- 风险等级、预算和影响范围；
- 审批对象、审批人、有效期和失效原因；
- 成功、业务拒绝、技术失败、超时、部分成功和结果未知；
- 业务对象 ID、验证结果、Trace 和人工接管状态。
