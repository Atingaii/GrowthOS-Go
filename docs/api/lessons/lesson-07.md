## 本节 API 变化

本节定义未来 API 的质量属性，没有新增、修改或删除真实 HTTP API、RPC、事件契约、MCP Tool 或 LLM 调用。`web/` 仍使用 Mock 数据。

以下内容是后续契约的验收约束，不是已发布接口：

| 约束 | 未来 API 必须说明 |
| --- | --- |
| 延迟 | 统计入口、P99 目标、超时预算和是否包含外部调用 |
| 可用性 | 有效请求、业务拒绝、系统失败和结果未知的口径 |
| 幂等 | 业务请求号生成方、保留期、重复请求响应和查询方式 |
| 一致性 | 响应表示受理、处理中还是事实已确认 |
| 鉴权 | 租户、角色、资源范围、审批和高风险失败关闭 |
| 可追踪 | `request_id`、`trace_id`、业务对象 ID 和错误码 |
| 降级 | 可回退结果、不可放松的不变量和用户提示 |
| 外部依赖 | GrowthOS 耗时、依赖方耗时和端到端耗时分开记录 |

## 超时与重试原则

- 查询接口可在不改变业务事实的前提下有限重试；
- 核心写接口必须使用业务幂等标识，超时后优先查询最终状态；
- 返回成功必须说明哪个业务事实已经确认；仅受理时不能返回“已到账”；
- 前端不得因为超时自动生成新的参与、领券或 Tool 执行标识；
- 具体超时值在真实接口出现时按调用链预算登记，不能从本节统一复制一个数字。
