## 阅读方式

每个章节记录至少说明：

- 新增、修改或删除了哪些接口；
- 哪个页面或组件调用接口；
- 请求参数、响应结构和错误码；
- 当前是 Mock、已联调还是已验收；
- 如何验证以及遗留问题。

如果某节没有前端 API 变化，也保留一条“无新增真实 API”的记录，避免读者误以为遗漏。
