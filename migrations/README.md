# 数据库迁移目录

这里存放 GrowthOS 的前向 MySQL Migration。第 13 节只建立执行机制，不提前创建业务表；首个真实迁移将在第 18 节加入。

规则：

- 文件放在 `sql/`，命名必须为六位递增版本号、下划线描述和 `.up.sql`，例如 `000001_create_strategy_and_award.up.sql`。
- 只新增前向迁移，不在应用里暴露 `down`、`drop` 或 `force`。
- 已经进入共享分支的迁移是不可变历史；修正结构时新增下一个版本，禁止改写旧文件。
- 每个文件应保持有限、可审查，并考虑 MySQL DDL 的隐式提交语义。
- API 账号与 Migration 账号必须分开；迁移命令使用专用凭据和单连接池。

迁移二进制会同时嵌入本说明和 `sql/` 子目录，因此发布产物不依赖宿主机上的相对路径。
